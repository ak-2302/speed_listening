## 教材本文と問題の権利確認

現在同梱している3教材（`daily-focus`、`morning-walk`、`notification-break`）の本文・問題文・選択肢・解説は、このプロジェクト用に作成したオリジナル文章です。青空文庫やニュース記事など第三者の本文は転載していません。各教材JSONに `source` と `license: "Project Original"` を記録しています。

この記録は、第三者の文章・翻訳・引用を後から追加する場合には適用されません。外部本文を追加する場合は、出典、著作者、利用許諾、改変条件を教材ごとに確認し、許諾範囲をJSONと配布物の権利表示へ反映します。

`npm run prepare:assets` は次の URL を固定して取得し、SHA-256 を照合してから `public/assets/` に配置する。

初回準備後のファイル合計は 109,937,690 バイト（非圧縮の辞書8ファイル、音声、WASM、WASMラッパー）。ブラウザの `PerformanceResourceTiming.transferSize` が取得できる場合は、今回の転送量を画面に表示する。キャッシュや圧縮により合計値と一致しない。

`npm run prepare:assets` は `openjtalkjs` の `LICENSE` と `THIRD_PARTY_NOTICES.md`、NVDA音声の `COPYRIGHT.txt` も `public/assets/licenses/` にコピーする。辞書の `COPYING` と合わせて、静的配布物に権利表示を含める。

WASMに含まれるソースの確認範囲は、openjtalkjs 0.1.0のnpm tarballに同梱された `vendor/open_jtalk` と `vendor/hts_engine_API` である。Open JTalkとHTS Engine APIのBSD系表示は各ソースファイルに含まれる。MeCab、Darts、Emscripten生成コードの個別ライセンス全文と、WASM生成時のビルド依存物の一覧は、公開前に上流の配布物と照合する。

## 未確認のまま公開しない項目

- `openjtalkjs` の `THIRD_PARTY_NOTICES.md` 自体が、依存コンポーネントとライセンス全文、著作権表示、対応ソースの追加を公開前の作業として残している。ファイルは配布物へコピーしたが、vendor の HTS Engine、Open JTalk、Emscripten生成物を、実際の配布物のバージョンと一緒に一覧化する作業は完了していない。
- 音声を NVDA 日本語版の実行環境で実聴し、読み、声質、長文分割時の間、高速再生時の差を記録する。この確認はWindows実機テストとしてPBI-01完了後に実施する。現在は同じ `tohoku-f01-neutral.htsvoice` を使うことまで確認済みで、完全一致は保証しない。
- スマートフォン実機、主要ブラウザの入力・生成・再生、転送量の初回実測、入力本文が外部へ送信されないことを端末側通信ログで確認する。

この調査は法的助言ではない。公開時は、実際に配布する静的ファイル、依存ライセンス、ソース提供方法と表示を法務・権利者の条件に照らして再確認する。

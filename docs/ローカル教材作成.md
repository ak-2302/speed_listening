# ローカル教材作成と音声生成

`scripts/build_materials.py` は、教材JSONの整合性を検証し、Open JTalkで生成した音声をOpus（Oggコンテナ）へ圧縮します。問題の正解・解説はJSONに保存し、Webアプリから読み込める形式を保ちます。

## 教材JSON

```json
[
  {
    "id": "daily-focus",
    "title": "集中力を保つ小さな工夫",
    "body": "教材本文です。",
    "questions": [
      {
        "id": "daily-focus-1",
        "prompt": "本文の内容はどれですか？",
        "choices": [
          { "id": "a", "text": "選択肢A" },
          { "id": "b", "text": "選択肢B" }
        ],
        "answerId": "a",
        "explanation": "本文では選択肢Aの内容を説明しています。"
      }
    ]
  }
]
```

## 実行例

教材JSONを`materials/`へ置き、プロジェクトルートで引数なしで実行すると、検証、`public/materials/`への教材JSON配置、`public/audio/`へのOpus Ogg生成、`public/materials/index.json`の更新をまとめて行います。

```sh
python3 scripts/build_materials.py
```

音声を生成せず、JSONの検証と配置だけ確認する場合は次のコマンドです。

```sh
python3 scripts/build_materials.py --validate-only
```

Open JTalkの場所や出力先を変更する場合は引数で指定できます。

```sh
python3 scripts/build_materials.py materials/ \
  --output-dir public/audio \
  --dictionary /path/to/open_jtalk/dic \
  --voice /path/to/tohoku-f01-neutral.htsvoice
```

GitHub Pagesへ配置する場合は、生成したOgg Opusを`public/audio/`へ置き、教材JSONの音声パスを教材IDから組み立てます。Opusは高圧縮ですが、対象ブラウザの`audio/ogg`対応を公開前に確認してください。音声・辞書・Open JTalkのライセンスとソース提供条件も確認してください。

macOSではHomebrewで`brew install open-jtalk`を実行すると、引数なしのコマンドをそのまま利用できます。Linuxなどで実行ファイルの場所が異なる場合は`--open-jtalk`で指定してください。ブラウザ用WASM資産をそのままPythonから実行する処理は、このスクリプトには含めていません。
